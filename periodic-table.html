A CHEMISTRY FIELD GUIDE

Reading the periodic table like a chemist

Every element around you — the oxygen you breathe, the iron in your blood, the silicon in this screen — has a fixed address on one chart. This guide walks through what that address means, then lets you open any of the 118 known elements to see it built up, shell by shell.

What the table actually sorts. Elements are ordered by atomic number — the number of protons in the nucleus — not by weight or age of discovery.

Rows run left to right as periods (energy shells added); columns run top to bottom as groups (families with similar outer‑shell electrons). The two detached rows are the lanthanides and actinides, pulled out only so the table stays a manageable width — they belong between groups 2 and 3 of periods 6 and 7.

Periods, groups and blocks

The table's shape isn't decoration — every row and column boundary marks a real pattern in how electrons fill up around the nucleus.

Periods (rows)

Each of the 7 rows starts a new electron shell. Moving right along a period, atoms get one more proton and one more electron, and properties shift gradually from metallic to nonmetallic.

Groups (columns)

Elements in the same column share the same number of electrons in their outermost shell, so they tend to react in similar ways — group 1 metals all react vigorously with water, for instance.

Blocks

The s, p, d and f blocks describe which type of orbital an atom's last electron went into. This page's ten color families are a more detailed, teaching-friendly version of that same idea.

Two trends worth remembering

Properties don't jump around randomly across the table — most change smoothly in one of two directions. Two of the clearest examples:

Atomic sizeShrinks across a period, grows down a group
Reactivity of metalsGrows down group 1, shrinks across a period

These two sketches illustrate direction, not measured values — open any element's record for its actual atomic number and mass.

About the data. Atomic numbers, symbols, standard atomic weights and periodic positions follow IUPAC conventions. Bracketed masses, e.g. [268], give the mass number of the longest-lived known isotope for elements with no stable one. Electron-shell diagrams use the simplified Bohr shell-filling model (shell capacities 2, 8, 18, 32…) taught at introductory level — real atoms beyond argon fill orbitals in a more intricate order. For elements 104 and above, and a few of the heaviest actinides, physical properties are theoretical predictions since only tiny quantities have ever been synthesized; these are marked "predicted" in each record.
